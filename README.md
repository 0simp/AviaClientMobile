# HOW TO INSTALL

# IOS

prerequisites: you MUST use the safari browser

1. Install a userscript manager extension. I recommend [Userscripts](https://apps.apple.com/us/app/userscripts/id1463298887) because it is free however if you want to spend 3 great british pounds to do the exact same thing you can use tampermonkey

2. Enable the userscript manager. To do this, go into settings -> safari, scroll down until you see the "general" section then tap the option that says "extensions". Then, find the userscript manager, tap it and enable "allow this extension". Also set the permission for "other websites" to "allow".

3. If you are using [Userscripts](https://apps.apple.com/us/app/userscripts/id1463298887), it should have put an app on your home screen. Open that app and set the userscripts directory

4. After doing that, download "Avia-Client-Mobile.user.js" from this repository and move it into the userscripts directory

5. Finally, open stoat in the safari browser. You should now have avia client mobile injected.

# ANDROID
